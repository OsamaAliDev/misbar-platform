# تدقيق مختبر الضوء — optics

**النطاق:** مراجعة للقراءة فقط لملف `audit-inputs/A-BEFORE/optics.json` ومصدر `src/simulations/OpticsSimulation.jsx` واللقطات الأربع أدناه، بدقة 1366×768. لم تُفتح صور `/home/ubuntu/upload`، ولم يُعدّل المصدر أو تُشغّل اختبارات أو متصفح أو MCP.

## الثيم والمصدر

عند **الاختيار الصريح** يتبدّل المختبر بصورة متسقة بين الفاتح والليلي في العربية والإنجليزية: الخلفيات والبطاقات والعناوين وأدوات التحكم والنتائج ووسطا الرسم تتبع الثيم. المصدر المراجع يستخدم رموز `surface-card` و`text-primary` و`text-secondary` و`accent-*` عبر `paint`، وحواف تسميات الزوايا تستخدم `var(--surface-card)`؛ لا تظهر فيه ألوان فاتحة/داكنة حرفية تتجاوز الثيم. هذه سلامة محلية للاختيار الصريح، وليست نفيًا لخلل الافتراضي العام الذي أكّده الوكيل الرئيسي عند غياب الاختيار: ليلي لمسارات المختبر/الألعاب وفاتح للكتالوج؛ لم يُعَد التحقق منه هنا.

## التباين والقراءة

القياسات المقدمة هي تباين DOM محسوب مع تركيب خلفيات الأسلاف. فقرة نصيحة شَرارة ظاهرة وكاملة في الحالات الأربع؛ تباينها **7.23635114683025:1** في الفاتح و**8.115677843715439:1** في الليلي. لذلك `minBodyContrast = 7.23635114683025`، ولا توجد فقرة جسم ظاهرة مقاسة دون 4.5:1.

توجد ثلاث مخالفات مؤكدة لنصوص أزرار ظاهرة في اللغتين والثيمين، وحجمها 16px ووزنها 700، لذا تتطلب 4.5:1:

- «محتاج مساعدة؟ / Need help?» أبيض على `rgb(239,107,94)` بتباين **3.0281824647434488:1**.
- «تحقق من التحدي / Check challenge» و«تشغيل / Play» أبيض على `rgb(47,143,224)` بتباين **3.4278911837075503:1**.

هذه الأزواج اللونية ثابتة عبر الثيمين حسب القياسات واللقطات؛ لا يُنسب تثبيتها إلى أسطر حرفية في مصدر المختبر لأن تعريف الأزرار المشتركة ليس ضمن المصدر المراجع. بقية النصوص غير SVG المقاسة الظاهرة تستوفي الحد المطلوب لكل عينة. لا يظهر قص أو تراكب يعيق قراءة العناوين أو التحدي أو النصيحة أو التسميات أو النتائج في اللقطات الأربع.

**حدود SVG:** أرقام تباين تسميات الرسم تستخدم خلفية السلف، بينما خلفية الماء مرسومة داخل SVG وحواف نصوص الزوايا مرسومة أيضًا. لا تكفي هذه الأرقام وحدها لإعلان نجاح AA لتلك التسميات فوق الخلفيات الفعلية؛ تبدو مقروءة بصريًا، وليست فقرات جسم، ولم تُحتسب في الحد الأدنى. خفوت الشعاع المنعكس ليس إخفاق نص؛ المصدر يربطه بمعامل الانعكاس العلمي.

## توصيات مقتصرة على CSS والثيم

تحسين زوجي ألوان نص/خلفية أزرار المساعدة والأزرار الزرقاء عبر متغيرات CSS الدلالية المشتركة حتى يبلغ النص 4.5:1 في الثيمين. الإبقاء على ربط الرسم برموز الثيم؛ وعند مراجعة ألوان تسميات SVG تُراعى خلفية الوسط الفعلية وحافة النص. لا حاجة لتغيير المحتوى العلمي أو المعادلات أو إحداثيات الرسم أو هندسته أو شدة الأشعة.
