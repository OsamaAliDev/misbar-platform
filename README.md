# مِسبار (Misbar) - Arabic EdTech Platform

"هنا مش بتتفرج — هنا بتجرب، وبتغلط، وبنقيس فهمك من طريقة تجربتك، مش من إجابتك."

## هيكل المشروع
- /src/app/: صفحات Next.js (الرئيسية، Playground، المعلم، ولي الأمر).
- /src/components/: مكونات واجهة المستخدم المشتركة.
- /supabase/: ملفات قاعدة البيانات و SQL.
- PRD.md: متطلبات المنتج.
- DESIGN.md: دليل التصميم والألوان.
