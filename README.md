# \# مِسبار (Misbar) — منصة التجارب العلمية والرياضية التفاعلية

# 

# \## 1. الرؤية ونطاق النسخة الأولى (PRD)

# \- \*\*المستخدمون:\*\* الأطفال (10–14 سنة) في مصر والوطن العربي، بالإضافة إلى المعلم وولي الأمر.

# \- \*\*المشكلة:\*\* صعوبة استيعاب مفاهيم الفيزياء والرياضيات والفلك من الشرح النظري الجامد.

# \- \*\*الشاشات الأساسية (V1):\*\*

# &#x20; 1. \*\*مكتبة التجارب (Catalog):\*\* عرض التجارب التفاعلية مع البحث والتصفية حسب المادة (الكل، الفيزياء، الرياضيات، الفلك).

# &#x20; 2. \*\*المشغّل التفاعلي الموحد (Playground):\*\* إطار موحّد لتشغيل المحاكاة التفاعلية (Canvas/SVG) مع أدوات التحكم، شريط النتائج الحية، ونافذة مساعدة التميمة «نُور».

# &#x20; 3. \*\*لوحة المعلم وولي الأمر:\*\* متابعة التقدم وترشيح التجارب بالاسم المستعار والرمز الكرتوني فقط.

# \- \*\*خارج نطاق النسخة الأولى (Out of Scope):\*\* جمع أي بيانات شخصية للأطفال (الاسم الحقيقي، البريد الإلكتروني، الصورة الشخصية، الهاتف)، أو بناء تطبيقات أصلية منفصلة للموبايل.

# \- \*\*الخصوصية:\*\* الالتزام الكامل بمبدأ تقليل البيانات (Data Minimization) والعمل بالاسم المستعار والأفاتار الهندسي فقط.

# 

# \## 2. نظام التصميم المعتمد (Locked Design Tokens)

# \- \*\*الاتجاه والخط:\*\* عربي بالكامل (`dir="rtl" lang="ar"`)، خط \*\*Cairo\*\* حصراً.

# \- \*\*الأسلوب البصري:\*\* تصميم مسطح بالكامل (Flat Design) — يُمنع منعاً باتاً استخدام الظلال (`box-shadow`)، التدرجات اللونية (`gradients`)، التأثيرات الزجاجية (`blur`)، أو الإيموجي.

# \- \*\*الحدود والزوايا:\*\* حدود صلبة `2px solid #E3D9CC`، وزوايا دائرية `20px` للبطاقات والأزرار.
